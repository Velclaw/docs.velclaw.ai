Hệ sinh thái VELCLAW 🦞

VELCLAW là một nền tảng cổng kết nối mã nguồn mở cấu trúc tĩnh kết hợp dữ liệu phi tập trung, giúp lập trình viên tối ưu hóa toàn diện hiệu năng phân phối tài liệu kỹ thuật và quản lý các package môi trường runtime tương tự như kiến trúc cốt lõi của OpenClaw hay CodeGrid.

🛡️ Self-hosted & Bảo mật

Vận hành độc lập trực tiếp ngay trên hạ tầng của bạn, toàn quyền kiểm soát dữ liệu cá nhân cấu hình hệ thống.

🚀 Phân phối tự động

Cập nhật nhanh chóng thông qua kiến trúc nạp dữ liệu động JSON tĩnh tối giản hóa tài nguyên máy chủ.

Khởi chạy hệ thống

Tích hợp cài đặt môi trường gói VELCLAW toàn cục bằng trình quản lý Node.js tương thích cao.

Cài đặt gói lệnh CLI:

npm install -g @velclaw/cli@latest

Khởi chạy Dashboard điều khiển:

velclaw onboard --dashboard
