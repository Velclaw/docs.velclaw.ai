# Bắt đầu

## Quy trình

1. Kết nối repository.
2. Khai báo runtime, build command và start command.
3. Cấu hình biến môi trường và health check.
4. Deploy.
5. Cấu hình DNS và HTTPS.
6. Xác minh production.

### Checklist

- Build thành công.
- CI kiểm tra đạt.
- Runtime khởi động.
- Health check đạt.
- Domain phân giải đúng.
- HTTPS không có lỗi chứng chỉ.
