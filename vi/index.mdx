# Velclaw

Velclaw là nền tảng kỹ thuật để xây dựng, triển khai, lưu trữ và vận hành ứng dụng hiện đại.

## Bắt đầu

Đi theo quy trình: **Source → CI/CD → Deploy → DNS → HTTPS → Health check**.

## Các sản phẩm

- **VelclawHost** — runtime và hosting.
- **VelclawDeploy** — delivery và deployment.
- **VelclawHub** — hệ sinh thái dự án và package.
- **Autoship** — tự động hóa CI/CD.

## Nguyên tắc

Mọi thay đổi production cần có khả năng kiểm tra, quan sát và khôi phục rõ ràng.
