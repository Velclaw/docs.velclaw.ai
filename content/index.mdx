# Velclaw Documentation

Velclaw Docs is the documentation hub for the platform's developer tooling, infrastructure, deployment, hosting, domains, automation, and AI-agent workflows.

## Choose a language

- [Tiếng Việt](/vi)
- [English](/en)

## Documentation architecture

The documentation is generated from the repository's verified JSON source under `docs/en` and `docs/vi`. Nextra renders that source as MDX so the site gains a structured sidebar, table of contents, code blocks, page navigation, dark/light theme controls, and full-text search.
