# Automation

Velclaw automation coordinates repetitive engineering operations such as CI/CD, dependency maintenance, deployment checks, and scheduled tasks.

## Automation principles

- Prefer deterministic commands.
- Fail closed when required configuration is missing.
- Log actionable errors.
- Keep secrets out of source control.
- Make destructive operations explicit.
- Provide a rollback or recovery path.

## Agent workflows

AI agents should operate within explicit repository and infrastructure boundaries. A workflow should clearly distinguish read, review, write, deploy, and production actions.
